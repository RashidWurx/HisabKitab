# Hisaab

Offline money manager for Android and iPhone, built for people with more than one income source. All data stays on the phone. See `docs/SPEC.md` for the full spec and `docs/PROJECT_STATE.md` for progress.

## Run

```powershell
flutter pub get
dart run build_runner build
flutter run
```

## Checks

```powershell
flutter analyze
flutter test
```

Google Drive and iCloud setup steps will be added here in Phase 8.
